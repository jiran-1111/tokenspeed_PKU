# MLA benchmark figure sources

The three `tokenspeed-mla-2-*.png` figures document upstream MLA GPU benchmarks
published by the LightSeek Foundation. They are preserved as the original PNG
bytes. Source URLs, download date, dimensions, and SHA-256 hashes are recorded
in [the source manifest](source_manifest.json).

The other three PNG files are the benchmark figures already distributed with
this TokenSpeed snapshot. The package README references all six images through
repository-relative paths.
