## 正确性判据的变化

新作业明确不要求不同硬件浮点结果逐位相同。此前strict raw/stop-aligned token对照保留为诊断证据，但不是第一阶段唯一硬门槛。0.8B现有stop-aligned 7/8不自动判失败，也不自动判通过：自回归近并列分叉须用同一输入/共同前缀的数值误差、margin、状态更新及稳定性证据解释；不能只说“BF16误差”就接受。误差阈值必须在正式验证前固定并说明来源，禁止为通过现有失败而事后扩大。

原总任务若仍要求更严格token一致性，继续在总项目清单独立保留；本次阶段报告按新作业实际判据验收，不重写历史结论。
