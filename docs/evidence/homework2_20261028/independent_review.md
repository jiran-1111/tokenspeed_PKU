2. 相同输入的完整/分片行投影对照明确展示额外BF16部分结果存储所引入的差异；跨层真实输入、门控、归一化和状态历史展示这些扰动的后续传播。自身输入参考与完整数据连接没有暴露出本批运行中应立即修正的参数加载、切分、HCCL返回、状态映射或错接输入问题。
3. 这仍不是设备所有中间算术的逐位模拟。除分片存储外，真实GEMM、RoPE、attention和激活的局部参考残差均必须保留。不能声称最终全部差异仅由某一次BF16存储造成。
4. 特别是FA参考并非全部落在`1e-4`以内。按保存的FP32数学加最终BF16候选，attention最大局部relative-L2为4B的`0.00328372`和9B的`0.00285222`，RoPE约为`0.00189414`和`0.00202992`。这些候选不仿真全部内核中间舍入，既不能据此直接判bug，也不能用更小的“全历史拼接投影最大误差”把它们隐藏。
5. 128组向量恒等式重建残差为零，证明导出向量的差分记账一致。它本身不是唯一物理因果解释；继承、分片和剩余局部误差的划分依赖共同参考与替换顺序，不能相加为因果百分比。
6. GDN历史复算由实际逐层操作数驱动，不是从embedding开始独立传播的CPU全模型。FA末步实际全KV直接读取，较早步骤的前缀由每次实际当前K/V重组，未逐步另读整个物理缓存。该范围已经公开，不能称作每个旧时间点的全部物理缓存均被独立导出。
7. 原84个共同前沿logits保持，原4B/9B greedy分叉没有修复。本次未认证分叉之后两条不同生成路径的全部32个输出，也未认证任意新输入、视觉功能或一般答案质量。
